# search_memos 的 query 参数说明

多个条件之间用空格隔开，表示「且」（都要满足）。
条件前加 `!` 表示取反，例如 `!#xxx` 表示不含标签 xxx 的笔记。
条件之间用 `|` 隔开（`|` 前后无空格）表示「或」。

优先级：**取反 > 或 > 且**

## 过滤条件

- `#xxx`：包含标签 xxx
- `.`：孤儿笔记（无任何引用/被引用关系）
- `$todo$`：包含待办
- `$unfinish$`：包含未完成待办
- `$done$`：包含已完成待办
- `$resource$`：包含附件
- `$image$`：包含图片附件
- `$video$`：包含视频附件
- `$audio$`：包含音频附件
- `$excalidraw$`：包含 Excalidraw 白板附件
- `$mindmap$`：包含思维导图附件
- `$drawio$`：包含 draw.io 图附件
- `$diagram$`：包含 diagram 图表附件
- `$textfile$`：包含文本类附件
- `$pdf$`：包含 PDF 附件
- `$word$`：包含 Word 附件
- `$excel$`：包含 Excel/CSV 附件
- `$ppt$`：包含 PPT 附件
- `$mdppt$`：包含 MD 幻灯片附件
- `$html$`：包含 HTML 附件
- `$epub$`：包含 EPUB 电子书附件
- `$publish$`：包含已发布（有公开链接）的附件
- `$gantt$`：包含甘特图附件
- `$cflow_db$`：包含 cflow 数据库附件
- `$inner_pic$`：包含笔记内嵌图片
- `$ref$`：引用了其他笔记
- `$refed$`：被其他笔记引用
- `$tag$`：有任意标签（可用 `!$tag$` 表示无标签）
- `$link$`：包含超链接
- `$code$`：包含代码块
- `$table$`：包含表格
- `$poi$`：包含地理位置 / POI
- `$title$`：有标题
- `$comment$`：包含评论
- `id=xx`：笔记 ID 精确等于 xx
- `recent:xx`：最近 xx 天内，例如 `recent:1` 表示今天的笔记，`recent:2` 表示这两天的笔记
- `title:xxx`：标题包含 xxx
- `word:xxx`：字数不少于 xxx
- 不匹配以上模式的普通词：内容或标题**包含**该词（最常用）

## 示例

- `xxx`：内容或标题包含 xxx
- `hello !#animal`：包含 hello，且不含 animal 标签
- `$done$ !$unfinish$`：有待办且全部已完成
- `$pdf$ #工作`：带 `#工作` 标签且包含 PDF 附件
- `python|py !#coding`：包含 python 或 py，且不含 coding 标签
- `recent:2 !$tag$`：最近 2 天内、且没有任何标签
- `#工作 recent:30`：带 `#工作` 标签且最近 30 天内

## 与 query_topic_memos 的区别

用户说不清精确用词、只知道大概意思时，用 `query_topic_memos`（语义匹配）。
能说出标签、关键词或明确过滤条件时，用 `search_memos`。
