笔记内容为 Markdown。除常见语法外，还需注意：

- 有序 / 无序列表不同层级之间用 **4 个空格** 缩进；无序列表每级以 `- ` 开头
- 行内 LaTeX 用 `$` 包裹，如 `$\alpha$`；行间公式前后用 `$$` 包裹
- 待办：`- [ ] 待办1`，已完成：`- [x] 待办2`

## cflow 特有语法

1. **标签**：`#xxx`，支持多级，如 `#项目/工作/需求分析`
2. **引用笔记**：写成代码形式，例如：

```
[显示名](/m/笔记id)
```

3. **高亮**：`==xxxx==`；方框：`[[[xxx]]]`
4. **下划线**：`___xxx___`；下波浪线：`~~~xxx~~~`
5. **遮罩**（默认隐藏，点击才显示）：`||xx||`
6. **折叠块**（长内容默认收起）：单独一行 `%%% 标题` 开头，单独一行 `%%%` 结尾，例如：

```
%%% 附录
附录内容
%%%
```

7. **Callout**（提示 / 注意 / 警告等）：

```
::: tip 标题
内容
:::
```

类型可选：`info` / `primary` / `question` / `help` / `faq` / `warn` / `caution` / `attention` / `danger` / `error` / `failure` / `success` / `done` / `check` / `bug` / `example` / `abstract` / `summary` / `tip` / `tips` / `hint` / `todo` / `quote` / `note`
